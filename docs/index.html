Snake Game with Q-Learning

I built this project to understand how far a simple table-based reinforcement learning setup can go without using a neural network. The snake learns by updating Q-values from rewards and eventually starts making better movement decisions on its own.

What It Is

A Snake game written in Python where the agent learns with classic Q-learning instead of a deep learning model.

How It Learns

The game state is represented using 11 hand-crafted features, and the agent updates a Q-table after every move.

Why I Built It

I wanted a reinforcement learning project that stayed readable and easy to reason about from end to end.

Core Setup

Project details

State Space

Uses 11 binary features covering danger detection, current direction, and food direction.

Action Space

The agent chooses between 4 actions: move straight, turn left, turn right, or make a U-turn.

Learning Loop

Q-values are updated from rewards using the standard Q-learning equation with epsilon-greedy exploration.

Interface

A Tkinter app lets you train the agent, watch the current policy, and reset the Q-table.

Learning Rule

Q-value update

Q(s, a) = Q(s, a) + alpha * (reward + gamma * max(Q(s', *)) - Q(s, a))

Here, alpha controls the learning rate, gamma controls how much future reward matters, and epsilon controls exploration during training.
